Settings for the calculator on Amazon pages.

Used to classify products with jev and estimate total package weight when Amazon only lists bare item weight. Create one at openrouter.ai/settings/keys. The key stays in this browser. Without it, the extension falls back to keyword matching and Amazon's listed weight.

Asks gpt-4.1-mini for the shipped weight when Amazon lists only the item weight. When this is off, the calculator uses Amazon's listed weight, and you can click "Estimate" in the calculator for a single product.
